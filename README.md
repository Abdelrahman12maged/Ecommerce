# One Plus Ecommerce App

**Ecommerce** is a **cross-platform e-commerce application** built with **Flutter** and **Dart**, supporting **mobile, tablet, and desktop** platforms. The app features **responsive UI/UX**, **Dark/Light mode**, **localization (Arabic & English)**, and **state management using Bloc/Cubit**.  

[📱 Google Play Link](#)  <!-- ضع رابط التطبيق إذا متاح -->

---

## 🌟 Features

- **Cross-Platform:** Runs on **mobile, tablet, and desktop** devices.  
- **Responsive & Adaptive UI:** Layouts adjust to different screen sizes.  
- **Dark/Light Mode:** Users can switch between themes easily.  
- **Localization:** Supports **Arabic & English** for wider accessibility.  
- **State Management:** Efficient data handling with **Bloc/Cubit**.  
- **RESTful API Integration:** Fetch products, manage carts, and handle orders.  
- **Firebase Integration:** Supports real-time updates and persistent storage.  
- **Scalable Architecture:** Clear separation of UI, business logic, and data layers.

## 🛠️ Libraries & Tools Used

- **flutter_bloc:** State management  
- **dio:** HTTP client for API calls  
- **equatable:** Value comparison for Bloc states  
- **go_router:** Navigation and routing  
- **device_preview:** Preview app on multiple device sizes  
- **data_connection_checker_tv:** Detects internet connection  
- **dartz:** Functional programming utilities  
- **smooth_page_indicator:** Page view indicators  
- **toast:** In-app notifications  
- **flutter_localizations:** Support for localization

## 📖 Application Overview

Ecommerce provides a **complete shopping experience**:

1. **Product Listings:** View and browse products with details.  
2. **Cart & Orders:** Add products to cart and manage orders.  
3. **Adaptive UI:** Seamless experience on mobile, tablet, and desktop.  
4. **Dark/Light Mode & Localization:** Users can choose themes and languages.  
5. **State Management & Persistence:** Efficient data handling for smooth UX.
